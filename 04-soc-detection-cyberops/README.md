# SOC Detection & Incident Reasoning (CyberOps Phase)

This phase focuses on **SOC-level detection thinking**, independent of tools or datasets.

The goal is to understand:
- what alerts a SOC should raise
- why many alerts fail
- how incidents are triaged and handled
- what security data can and cannot tell us

This phase is paired with the **Cisco CyberOps Associate** certification and
acts as the conceptual foundation for later data-driven validation using CICIDS 2017.

---

## Scope of This Phase

This phase is intentionally **non-implementation-heavy**.

✔ Detection logic  
✔ Alert reasoning  
✔ Incident lifecycle  
✔ False positives  
✔ Detection gaps  

❌ No SIEM dashboards  
❌ No ML models  
❌ No datasets

## How This Connects to CICIDS

This phase defines **what should be detected**.

The later CICIDS phase evaluates:
- whether those detections are feasible
- how noisy they are
- why context matters

Detection logic first.  
Data validation later.
